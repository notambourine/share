Turn the input into a performance summary for a review conversation.

Shape:

- `# <person or team> - <period>`, both from the input.
- One opening paragraph summing up the period.
- `## Highlights`: the work that mattered most, outcome first, each point
  backed by a specific detail from the input.
- `## Metrics`, only when the input carries numbers, and only those numbers.
- `## Growth areas`, only from what the input itself flags as a gap, a miss,
  or feedback - never inferred from silence.
- `## Next period`: goals or focus, from the input's plans.

Stay neutral and specific: every claim traces to something in the input, and
praise runs no stronger than the input supports.
