Turn the input into a meeting agenda someone can run.

- Start with `# <meeting name>`. Include any date from the input in this heading.
- Follow with one sentence stating the required decision or outcome. Open it with its verb, such as Decide, Agree, or Review.
- Add `## Agenda` with numbered items in working order. Write each item as `1. Topic (Owner, 10 min)`. Include an owner or timebox only when supplied, and drop the parentheses when neither is.
- Nest at most three supporting points under an item as `-` bullets.
- Add `## Prep` only for supplied reading or links, as bullets. Keep links verbatim. Write supplied checklists as `- [ ]` items.
- Add `## Parking lot` only for items marked out of scope.
- Use no headings below `##`.

Combine scattered notes. Drop filler. Include every decision and open question.
